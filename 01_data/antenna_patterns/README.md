# WinProp 天线方向图

本目录收录 `ISO.apa`、一个 0° 方向图、四个随机方向图（94°、193°、203°、313°）以及随机方位角 CSV，均已进入 Git。方向图文件名记录 65°/8° 波束宽度与 6.3 dBi 增益。

这些是 WinProp 实验使用的 APA 文件。当前 Sionna 标签由 Sionna 配置和代码生成方向图；不要把这里的四个固定方位角当作整个 Sionna 数据集的方向设置。

生成代码：[`generate_winprop_antenna_patterns.py`](../../scripts/generate_winprop_antenna_patterns.py)。
