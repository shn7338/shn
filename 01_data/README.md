# 数据目录

| 子目录 | 内容 | GitHub 收录 |
| --- | --- | --- |
| `512mdata/` | WinProp tile 原始数据、`.odb` 和网格输出 | 索引与生成报告；原始 tile 文件留在本机 |
| `antenna_patterns/` | 仿真使用的天线方向图 | `.apa` 文件和方向记录 |
| `normalized_4m_v1/` | 4 m 归一化数据 | 划分、归一化参数与汇总；数组留在本机 |
| `prediction_records/` | 预测准备与修复记录 | 四份清单及说明 |
| `prepared_4m/` | 预处理后的 4 m 数据 | 批处理汇总；数组留在本机 |
| `raw_datasets/` | 原始数据包 | 仅目录说明 |

本机完整数据约 79 GiB。清单中的绝对路径来自原实验电脑，克隆仓库后不能直接当作本地数据路径使用。
