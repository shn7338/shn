# 隐式基站参数 Pilot v2 实验摘要

## 结论

只输入建筑高度、100 个稀疏信号值和掩码的端到端方案可行。完整适配后测试集 RMSE 为 **6.812 dB**，稀疏校准基线为 **12.332 dB**。

## 对照结果

| 模型组合 | 基站位置 | 测试 RMSE (dB) |
|---|---|---:|
| 原三级模型 | 网络估计 | 7.886 |
| 仅适配 Stage2-B v1 | 网络估计 | 7.284 |
| 新 Stage1/2-A＋旧 Stage2-B | 网络估计 | 6.910 |
| 全部适配 v2 | 网络估计 | 6.812 |
| 全部适配 v2 | 真实 | 6.429 |

- 相对原模型累计提升：**1.074 dB**。
- 相对上一版完整管线提升：**0.472 dB**。
- Stage1/2-A 的直接贡献：**0.374 dB**。
- Stage2-B v2 的附加贡献：**0.098 dB**。
- 预测位置相对真实位置的最终损失：**0.383 dB**。
- 相对稀疏校准基线的收益：**5.520 dB**。

## 隐变量估计误差

- 位置：平均 5.441 px，中位数 3.147 px，P90 11.316 px。
- 有效功率 MAE：1.860 dB。
- 方位角 MAE：12.807°。

## 下一步

当前预测位置与真实位置仍相差 0.383 dB，已经大于 Stage2-B v2 的附加收益。下一步优先增强定位鲁棒性，或对 Stage1/2-A 加入位置不确定性训练。
