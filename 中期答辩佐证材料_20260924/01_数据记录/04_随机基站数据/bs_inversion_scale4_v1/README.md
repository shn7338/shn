# Scale-4 归档说明的勘误

同目录 `DATASET_README.md` 是生成时的原始记录，误用了 Pilot 模板：标题、场景/站点/样本数量和四象限采样描述均不适用于 Scale-4。

正确数据为：1,536 个建筑场景、6,144 个站点、30,720 张传播图、24,576 个方向样本；位置按距场景中心的径向区间均衡采样。原归一化数值属于 Scale-4，但实际模型是否使用这些统计须按训练代码判断。

请阅读 [已修正的数据说明](../../../../02_inversion/bs_inversion_scale4_v1/DATASET_README.md)。本目录原 FINAL_REPORT、验证记录和样本保留原样以便哈希核对；不要依据旧标题把 Scale-4 当成 Pilot。
